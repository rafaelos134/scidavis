# Documentation

| Folder | Contents |
|---|---|
| `manual/` | User manual in LaTeX (`scidavis.tex` is the main file; `pics/` and `icons/` hold the figures). The published version is at <https://highperformancecoder.github.io/scidavis-handbook/>. |
| `api/` | Doxygen configuration for the code documentation: `cd docs/api && doxygen` writes `API/html/`. `Doxyversion` is updated by `scripts/makeRelease.sh`. |
| `screenshots/` | Screenshots used by the README and the application metadata (`scidavis/data/scidavis.appdata.xml`). |
| `ROADMAP.md` | Planned improvements with the steps for each one (in Portuguese). |

The developer documentation (features, architecture, where the calculations are, themes and
icons, ...) is on the [project wiki](https://github.com/rafaelos134/scidavis/wiki); the contributor
guide is [CONTRIBUTING.md](../CONTRIBUTING.md).
